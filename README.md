# Java Collection Framework Practice

This repository contains my notes and practice work for the Java Collection Framework.

## Contents

- `COLLECTION_FRAMEWORK.pdf` - topic notes (List, Set, Queue, Map, Iterator, Collections class, Comparable and Comparator)
- `CollectionPractice.java` - practice exercises for each topic

## Topics covered

- List: ArrayList, LinkedList, Vector, Stack
- Set: HashSet, LinkedHashSet, TreeSet
- Queue: Queue, PriorityQueue
- Map: HashMap, LinkedHashMap, TreeMap
- Iterator and ListIterator
- Collections utility class
- Comparable and Comparator
- Common exceptions with collections

## How to run

```
javac CollectionPractice.java
java CollectionPractice
```
